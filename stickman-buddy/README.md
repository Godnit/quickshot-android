# Stick Man Buddy — Android 8.1 والأقدم

تطبيق أندرويد Java يعرض شخصية Stick Man كنافذة عائمة فوق التطبيقات.

## التوافق

- Android 5.0 (API 21) فأحدث، ويشمل Android 8.1 (API 27).
- `minSdkVersion 21` و`targetSdkVersion 27`.
- لا يحتاج اتصالاً بالإنترنت بعد تثبيته.

## التشغيل من المصدر

1. افتح المجلد في Android Studio.
2. اضغط **Build > Build APK(s)**.
3. ثبّت `app/build/outputs/apk/debug/app-debug.apk` على الهاتف.
4. افتح التطبيق، اضغط **فتح إعدادات الصلاحية** وفعّل **السماح بالظهور فوق التطبيقات**.
5. عد إلى التطبيق واضغط **تشغيل Stick Man**.

## التفاعل

- اسحب الشخصية بإصبعك لتحريكها فوق أي تطبيق.
- اضغط الشخصية لترى رداً.
- الأزرار السفلية: 👍، 🤝، و↗ لتحريكها إلى موضع آخر.
- الخدمة تعمل بإشعار foreground حتى لا يوقفها النظام بسهولة.

## بناء APK من GitHub

كل push إلى فرع `main` يشغّل GitHub Actions ويبني APK تجريبياً. ستجد الملف في تبويب **Actions > Build Android APK > Artifacts**.
