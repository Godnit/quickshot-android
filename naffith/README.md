# نفّذ (Naffith)

نسخة أولية من مساعد أندرويد يعمل بالكتابة فقط، ومتوافقة مع Android 8.1 وما بعده.

## ما يعمل في هذه النسخة

- فتح التطبيقات الشائعة مثل يوتيوب وChrome والإعدادات والملفات.
- البحث في يوتيوب وفتح النتائج.
- فتح منتقي الملفات.
- أوامر عربية محلية لا تحتاج إلى API أو اتصال بالذكاء الاصطناعي.
- نقطة توسعة `LocalBrain` لإضافة نموذج ذكاء محلي لاحقًا.

## البناء

افتح المجلد في Android Studio، ثم نفّذ Build > Make Project. أقل إصدار مدعوم هو API 27 (Android 8.1).

## أمثلة

- `افتح يوتيوب`
- `ابحث في يوتيوب عن تعلم البرمجة`
- `افتح الملفات`
- `افتح الإعدادات`
- `مساعدة`

هذه نسخة آمنة أولية: الأوامر غير المعروفة لا تنفّذ شيئًا. سيتم إضافة التحكم في الشاشة والنموذج المحلي بعد اختبار الأساسيات.
