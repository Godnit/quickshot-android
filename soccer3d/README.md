# Soccer 3D ⚽

لعبة كرة قدم ثلاثية الأبعاد خفيفة مبنية بـ Godot 4، تدعم Android 8.1 (API 27) فما فوق.

## المزايا
- مباراة 5 ضد 5، لاعبين وحارس مرمى مبسطين بالذكاء الاصطناعي.
- تمرير، تسديد، تزحلق، مراوغة وحركة WASD/أزرار لمس.
- أهداف ونتيجة ومؤقت ومشهد ملعب ثلاثي الأبعاد.
- قائمة إعدادات واختيار ألوان الفرق.

## التشغيل
افتح المشروع في Godot 4.2+ ثم شغّل `main.tscn`. للتصدير استخدم Android مع Minimum SDK 27.
